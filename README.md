# Documentação: Pesquisa de Preços Lite

No ramo principal, criar pasta "docs"

Nessa pasta, criar as pastas 
- "Imagens" > onde são colocadas todas as imagens. Atenção para a letra maiúscula no nome da pasta e use apenas arquivos com nomes sem espaço e sem caracteres especiais, incluindo ç e acentos
- "css" > onde consta o arquivo extra.css
- "js" > onde constam os arquivos "custom.js" e "font-size.js"

Nessa pasta também constam:
- Os arquivos com as seções do manual em extenção ".md"
- arquivo "custom.css"
- arquivo "index.md" com a página inicial e os links para cada uma das seções
- arquivo "manual-completo.md", que compila todas as seções
